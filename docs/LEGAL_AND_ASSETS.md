# Legal and Asset Boundary

This repository contains compatibility code and metadata only. It must not
contain or distribute the game disc image, executable, extracted game assets,
Sony BIOS files, memory cards, PCSX2 binaries, or locally generated recompiled
game source. Users provide their own matching U.S. version 1.01 dump.

Local inputs live under ignored `emu/` and `Haunting Ground (USA)/` directories.
Generated output, traces, and captures live under ignored build/output folders.
Necessary temporary images may only live in ignored `UNEEDED images/`.

PS2Recomp and PCSX2 may be consulted under their open-source licenses. Any
specific reused/adapted implementation must be entered in
`docs/SOURCE_PROVENANCE.md` with revision, path, authorship/notice handling, and
license compatibility reviewed before distribution.
